Sobre o projeto

Este projeto foi desenvolvido em Java utilizando o NetBeans, com o objetivo de trabalhar os conhecimentos adquiridos durante meus estudos em Engenharia de Software.

Tecnologias utilizadas

* Java
* Apache NetBeans

## Como executar

1. Instale o JDK (Java Development Kit).
2. Abra o projeto no Apache NetBeans.
3. Configure o ambiente Java, se necessário.
4. Execute a classe principal do programa.

## Autor

Desenvolvido como projeto de estudos em Engenharia de Software.
